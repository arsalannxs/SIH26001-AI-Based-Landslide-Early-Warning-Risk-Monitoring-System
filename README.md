# 🏔️ AI-Based Landslide Risk Monitoring System

### Smart India Hackathon 2026 — SIH26001

An **AI-powered disaster management system** designed to monitor and predict landslide risks in the **North Eastern Region (NER) of India**.

## 🎯 Problem

The North Eastern Region frequently faces landslides due to heavy rainfall, steep terrain, geological conditions, and human activities. These events can damage roads, infrastructure, and affect local communities.

## 💡 Solution

Our system combines **AI, rainfall data, terrain information, GIS, and historical landslide data** to identify areas with increasing landslide risk.

### Key Features

- 🗺️ **Risk Map** — Visualizes landslide-prone areas.
- 🤖 **AI Risk Prediction** — Estimates landslide risk using environmental data.
- 🌧️ **Rainfall Monitoring** — Tracks rainfall-related risk factors.
- 🚨 **Early Warning** — Generates alerts when risk increases.
- 📊 **Admin Dashboard** — Helps authorities monitor and manage risks.
- 📱 **Citizen Reporting** — Allows users to report landslides and hazards.

## ⚙️ Technology

- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS
- **Backend:** Node.js, TypeScript
- **AI:** Machine Learning / AI
- **Maps:** GIS / Geospatial Data
- **Database:** Spatial Database
